# LostBits Beta Test

Baixe os arquivos do lançamento mais novo (Releases) e siga o COMO_INSTALAR.txt.

```
LostBits Beta Test - como instalar
==================================

1. Baixe todos os arquivos .zip deste lançamento.
2. Desligue o portátil e coloque o cartão de memória dos jogos no PC.
3. Extraia TODOS os .zip na raiz desse cartão, isto é, na pasta onde fica a pasta "ports"
   (ArkOS e clones: a unidade EASYROMS; EmuELEC, AmberELEC e ROCKNIX: a pasta roms).
   Quando o Windows perguntar, escolha substituir os arquivos.
   Fica assim:  ports/LostBits Beta Test.sh   ports/lostbits-beta/   lostbits/<jogos>/
4. Devolva o cartão e ligue o portátil. Abra Ports > "LostBits Beta Test" (se não aparecer, reinicie o aparelho
   ou use "Atualizar lista de jogos" no menu Start).

Os jogos já vêm instalados: é só escolher e Jogar. A Beta não usa a internet.
Para sair de um jogo: FN + Start duas vezes (ou o atalho de sair do seu firmware).


LostBits Beta Test - how to install
===================================

1. Download every .zip file of this release.
2. Turn the handheld off and put its game memory card in your PC.
3. Extract ALL the .zip files to the ROOT of that card, i.e. the folder that holds the "ports" folder
   (ArkOS and clones: the EASYROMS drive; EmuELEC, AmberELEC, ROCKNIX: the roms folder). Replace files if asked.
   Result:  ports/LostBits Beta Test.sh   ports/lostbits-beta/   lostbits/<games>/
4. Put the card back and turn the handheld on. Open Ports > "LostBits Beta Test" (if it is missing, restart the
   handheld or use "Update game lists" in the Start menu).

The games come already installed: just pick one and Play. The Beta does not use the internet.
To quit a game: FN + Start twice (or your firmware's quit shortcut).
```
