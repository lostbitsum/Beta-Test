# LostBits Beta Test

Baixe os arquivos do lançamento mais novo (Releases) e siga o COMO_INSTALAR.txt.

```
LostBits Beta Test - como instalar
==================================

1. Baixe todos os arquivos .zip deste lançamento.
2. Desligue o portátil e coloque o cartão de memória dos jogos no PC.
3. Extraia TODOS os .zip na raiz desse cartão, isto é, na pasta onde fica a pasta "ports"
   (ArkOS e clones: a unidade EASYROMS; EmuELEC, AmberELEC e ROCKNIX: a pasta roms).
   No Windows: clique com o botão direito no .zip > "Extrair tudo...", APAGUE o nome de pasta que ele sugere e deixe
   só a letra do cartão (ex.: F:\). Não use "Extrair para <nome>\": isso cria uma pasta a mais e nada funciona.
   Quando o Windows perguntar, escolha substituir os arquivos.
   Fica assim:  ports/LostBits Beta Test.sh   ports/lostbits-beta/   ports_scripts/LostBits Beta Test.sh
                lostbits/<jogos>/
   (a pasta ports_scripts é a que o menu Ports do EmuELEC lê; nos outros firmwares ela só fica sobrando)
4. Depois de extrair, pode apagar os .zip do cartão (não precisa deixar nenhum .zip dentro de "ports").
5. Devolva o cartão e ligue o portátil. Abra Ports > "LostBits Beta Test" (se não aparecer, reinicie o aparelho
   ou use "Atualizar lista de jogos" no menu Start).

Os jogos já vêm instalados: é só escolher e Jogar. A Beta não usa a internet.
Para sair de um jogo: FN + Start duas vezes (ou o atalho de sair do seu firmware).

Atualizando uma versão anterior: apague os .zip antigos, baixe os novos e extraia todos do mesmo jeito, substituindo
os arquivos. Os saves (pasta hdd de cada jogo) não estão nos .zip e continuam.


LostBits Beta Test - how to install
===================================

1. Download every .zip file of this release.
2. Turn the handheld off and put its game memory card in your PC.
3. Extract ALL the .zip files to the ROOT of that card, i.e. the folder that holds the "ports" folder
   (ArkOS and clones: the EASYROMS drive; EmuELEC, AmberELEC, ROCKNIX: the roms folder).
   On Windows: right-click the .zip > "Extract All...", DELETE the folder name it suggests and keep only the card's
   drive letter (e.g. F:\). Do not use "Extract to <name>\": it adds an extra folder and nothing works.
   Replace files if asked.
   Result:  ports/LostBits Beta Test.sh   ports/lostbits-beta/   ports_scripts/LostBits Beta Test.sh
            lostbits/<games>/
   (ports_scripts is the folder EmuELEC's Ports menu reads; on other firmwares it is simply unused)
4. After extracting you may delete the .zip files from the card (no .zip needs to stay inside "ports").
5. Put the card back and turn the handheld on. Open Ports > "LostBits Beta Test" (if it is missing, restart the
   handheld or use "Update game lists" in the Start menu).

The games come already installed: just pick one and Play. The Beta does not use the internet.
To quit a game: FN + Start twice (or your firmware's quit shortcut).

Updating an earlier version: delete the old .zip files, download the new ones and extract them all the same way,
replacing files. Saves (each game's hdd folder) are not in the .zip files and are kept.
```
